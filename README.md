## 🚀 Sobre a IDIGTEC

A **IDIGTEC** é especializada em engenharia de sistemas modernos, combinando tecnologia de ponta e IA para criar produtos resilientes, inteligentes e escaláveis.

- 📍 **Localização:** Cidade da Beira, Província de Sofala, Moçambique 🇲🇿
- 🌐 **Website Oficial:** [idigtec.com](https://idigtec.com)
- 💼 **Contato Comercial:** [info@idigtec.com](mailto:info@idigtec.com)
- 🤖 **Foco Principal:** Agentes Autônomos de IA, Gateways Multimodais (Texto, Áudio, Vídeo, Documentos), CRMs Inteligentes e Infraestrutura Cloud.
